# 🏎️ Formula Horizon — 3D Racing Game

A 3D Formula-style racing game developed using **Unity and C#**, featuring exciting racing experiences across Desert and Forest environments.

## 🎮 Play the Game

### [🏁 Play Formula Horizon Online](https://saisurya2110.itch.io/formula-horizon)

Play directly in your browser using Unity WebGL — no installation required!

## 📌 About the Project

Formula Horizon is a 3D racing game inspired by Formula-style motorsport. The game provides an immersive racing experience with challenging circuits, AI-controlled opponents, multiple laps, and different environments.

This project was developed as part of a game development project to explore 3D game design, physics, gameplay mechanics, and Unity development.

## ✨ Features

- 🏎️ 3D Formula-style racing gameplay
- 🏜️ Desert racing environment
- 🌲 Forest racing environment
- 🤖 AI-controlled rival racers
- 🏁 Multi-lap racing system
- 🎮 Interactive vehicle controls
- 📊 Race timing and best-time tracking
- 🌐 Playable through WebGL in a browser

## 🕹️ Controls

| Key   | Action           |
| ----- | ---------------- |
| W / ↑ | Accelerate       |
| S / ↓ | Brake / Reverse  |
| A / ← | Steer Left       |
| D / → | Steer Right      |
| Space | Handbrake        |
| B     | Recover to Track |
| R     | Restart Race     |
| Esc   | Pause            |

## 🚀 Getting Started

### Run the game online

1. Visit the [Formula Horizon Game Page](https://saisurya2110.itch.io/formula-horizon).
2. Click the game window.
3. Start racing!

### Run the project locally

1. Clone this repository:
   ```bash
   git clone https://github.com/SaiSurya2110/Formula-Horizon.git
   ```
2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the cloned project folder.
5. Open it using **Unity 2021.3.38f1**.
6. Open the main scene and click **Play**.
